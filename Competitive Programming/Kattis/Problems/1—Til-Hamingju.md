
# TilHamingju

Prints a birthday greeting to **Forritunarkeppni framhaldsskólanna**.

## Source

```java
public class TilHamingju {

    private static final String GREETING =
            "TIL HAMINGJU MEÐ AFMÆLIÐ FORRITUNARKEPPNI FRAMHALDSSKÓLANNA!";

    public static void main(String[] args) {
        System.out.println(GREETING);
    }
}
```

## Run it

```bash
javac -encoding UTF-8 TilHamingju.java
java -Dfile.encoding=UTF-8 TilHamingju
```
